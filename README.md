One line, at most 140 characters, of an out-of-office auto-reply, the funniest I can make it: Out of office until Monday. My inbox is unsupervised now, so keep your email short, it will be judged on arrival.

## Run it

```sh
MAKEFUN_OUTPUT_DIR=out python3 main.py
```

The program writes `entry.txt` (one line, 113 characters) to the output directory. It uses only the Python 3.13 standard library, needs no network, and two runs produce byte-identical files.
